# AI Interviewer — frontend

Next.js (App Router) + TypeScript + Tailwind CSS. See the [project root
README](../README.md) for the full picture (architecture, backend, roadmap).

## Run

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

Open http://localhost:3000. Requires the backend running on :8000 (see
`../backend/README` instructions in the root README) — the dashboard shows a
live connection error state if it can't reach it.

## Structure

- `app/` — routes (App Router)
- `lib/` — client-side helpers (e.g. `lib/api.ts`, the backend fetch wrapper)

`AGENTS.md` / `CLAUDE.md` are auto-generated by Next.js on `next dev` as a
pointer to the framework's bundled docs (this project is on Next.js 16,
which has notable breaking changes from earlier versions) — safe to ignore,
regenerated automatically, fine to commit.
